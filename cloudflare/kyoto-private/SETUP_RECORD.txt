------------------------------

六、從零建立同類型網站的流程
----------------------------
A. Cloudflare Worker
1. Cloudflare Dashboard → Compute → Workers & Pages。
2. Create application → Start with Hello World。
3. Worker 命名。
4. Deploy。
5. 連 GitHub repository。
6. 如果是 monorepo，設定 Root directory。
7. Deploy command 使用 npx wrangler deploy。

本次為了避免在手機 Cloudflare 程式編輯器大量貼程式，Worker 程式放 GitHub，由 Cloudflare Git integration 自動部署。

B. 登入保護
目前不是 Cloudflare Access。
原因：Zero Trust / Access 的啟用流程要求設定 billing/payment method，這次決定不綁卡。

目前採 Worker 內建 HTTP Basic Auth：
- Runtime Secret：AUTH_USERS
- 程式收到 Authorization Basic Header 後驗證。
- 未通過即回 401。

C. Google Drive API
1. Google Cloud Console 選一個 Project。
2. API 和服務 → 程式庫。
3. 搜尋 Google Drive API。
4. 啟用。
5. IAM 與管理 → 服務帳戶。
6. 建立 Service Account。
7. 不必替它加入專案 IAM 角色。
8. Service Account → 金鑰 → 新增鍵 → 建立新的金鑰 → JSON。
9. 下載 JSON。
10. JSON 不可公開。

D. Cloudflare 加 Google 憑證
1. Worker → Settings。
2. Runtime variables and secrets。
3. Add variable。
4. Key = GOOGLE_SERVICE_ACCOUNT_JSON
5. 勾 Secret。
6. Value = Service Account JSON 完整內容。
7. Add variable and deploy。

E. Drive 分享
把要顯示的 HTML 檔分享給 Service Account Email，權限 Viewer。

F. Worker 讀取方式
Worker 會：
1. 從 GOOGLE_SERVICE_ACCOUNT_JSON 取得 client_email/private_key。
2. 建立 RS256 JWT。
3. 向 https://oauth2.googleapis.com/token 換取 access token。
4. scope 使用 https://www.googleapis.com/auth/drive.readonly
5. 用 Google Drive API：
   GET https://www.googleapis.com/drive/v3/files/{FILE_ID}?alt=media
6. 把 HTML 原樣回傳給瀏覽器。

七、安全界線
------------
可以寫進 GitHub：
- Service Account Email
- Google Cloud Project ID
- Google Drive File ID
- Worker URL
- Route
- Secret 名稱
- 程式碼

不可寫進 GitHub / 聊天 / 截圖：
- AUTH_USERS 實際 Value
- 登入密碼
- GOOGLE_SERVICE_ACCOUNT_JSON 實際內容
- private_key
- private_key_id
- OAuth client_secret
- Cloudflare API Token 實際值
- 2FA / recovery code

如果 Service Account JSON 曾外洩：
Google Cloud → Service Account → 金鑰 → 刪除該 Key → 建立新的 JSON Key → 更新 Cloudflare Secret。

十一、目前設計原則
------------------
- Google Drive = Source of Truth
- Cloudflare Worker = Gateway / Viewer
- GitHub = Worker code only
- Cloudflare Runtime Secrets = Credentials
- Worker URL = Private web entry
- ChatGPT 一般 Chat = 可持續維護 Drive HTML 與 GitHub Worker

十二、重要備註
--------------
1. 目前登入是 HTTP Basic Auth，不是 Google SSO。
2. Email 在 AUTH_USERS 中只是登入名稱；真正授權條件是 Email + Password 配對。
3. 若未來需要真正 Google Account SSO、逐帳號身份管理，可另行改用 OAuth / Access 類方案。
4. Google Drive File ID 本身不是存取憑證；真正的 Drive 權限由 Service Account sharing + Service Account key 控制。
5. 本 repo 是 Public，因此任何真正私人資料都必須繼續留在 Google Drive 或 Cloudflare Secret。
