Day 1｜7/9（四）關西空港 → 奈良 → 京都入住

今日摘要

這天重點不是京都市區，而是「降落後先處理大行李，再利用第一天去奈良」。主線收在飯店，不排夜間遠程移動。

行程 Outline

06:05–07:40｜抵達關西空港・寄送行李

先把入境、領行李、出關與 Airporter 完成，後面才可以輕裝去奈良。這段終點只需要確認自己已經在關西空港完成所有入境與寄送流程。

台湾桃園国際空港Jetstar GK50関西国際空港入境領行李Airporter：2 件大行李送飯店
🎯 終點：関西国際空港
07:40–09:40｜關西空港 → 難波 → 奈良

這段是交通主線：南海到難波，再走到大阪難波轉近鐵。規劃方向時只要把終點設成近鉄奈良駅。

南海 関西空港駅南海なんば駅大阪難波駅近鉄奈良駅
🎯 終點：近鉄奈良駅
09:50–12:00｜奈良公園・東大寺

從近鉄奈良駅出來後，先進奈良公園，再往東大寺。這是第一個核心景點段落，終點放東大寺，方向最清楚。

近鉄奈良駅奈良公園東大寺
🎯 終點：東大寺
12:00–13:00｜奈良午餐

午餐不要拉太遠，保留在東大寺、奈良公園、近鉄奈良駅之間。若排隊太長，就改用柿葉壽司或車站周邊。

東大寺周邊奈良公園周邊近鉄奈良駅周邊
🎯 終點：近鉄奈良駅周邊午餐
13:00–14:30｜春日大社

午餐後往春日大社，走森林參道與石燈籠。這段不要塞太多店，重點是神社氛圍。

奈良公園春日大社表参道春日大社
🎯 終點：春日大社
14:30–16:10｜奈良散策・回車站

這段是緩衝。體力夠就補興福寺或猿沢池；體力不足就直接往近鉄奈良駅回收。

春日大社奈良公園興福寺或猿沢池可選近鉄奈良駅
🎯 終點：近鉄奈良駅
16:30–19:00｜奈良 → 京都 → 飯店 check in

回京都後不先逛街，先到飯店確認 check in 與 Airporter 行李。這段終點就是飯店。

近鉄奈良駅近鉄京都駅地下鉄 京都駅地下鉄 四条駅イビススタイルズ京都四条
🎯 終點：イビススタイルズ京都四条
19:00 後｜晚餐・休息

第一晚只留在四条烏丸。不要去祇園、先斗町或京都站，避免第一天太累。

四条烏丸周邊晚餐回飯店休息
🎯 終點：四条烏丸

就地備選｜只放奈良與四条烏丸

奈良午餐・點心

都在奈良動線附近。

Day 2｜7/10（五）清水寺 → 清水燒 → 高島屋 → 祇園祭

今日摘要

這天是由東山高處一路下到祇園、四条河原町，再接祇園祭晚間活動。備選只放清水東山、高島屋、四条河原町。

行程 Outline

08:30–10:30｜飯店 → 清水寺

直接搭車上到清水寺方向，省體力。這段終點設清水寺，之後一路下坡逛街比較順。

イビススタイルズ京都四条五条坂／茶わん坂音羽山 清水寺
🎯 終點：音羽山 清水寺
10:30–13:15｜清水坂・清水燒・二寧坂・三年坂

這段是清水燒與老街散策，邊走邊看，不需要鎖死每一家店。終點放二寧坂，方便銜接八坂之塔與祇園方向。

清水坂京清水焼 朝日堂あさひ坂産寧坂（三年坂）二寧坂午餐排在周邊
🎯 終點：二寧坂
13:15–14:30｜八坂之塔 → 祇園方向

從二寧坂往八坂之塔、ねねの道、八坂神社下來。這段是從觀光老街轉進祇園祭核心區的過渡。

法観寺 八坂の塔ねねの道八坂神社祇園
🎯 終點：八坂神社
14:30–16:20｜京都高島屋

高島屋是這天的休息、甜點、冷氣、晚餐候選據點。它離四条河原町與神輿洗動線近。

祇園四条河原町京都髙島屋S.C.
🎯 終點：京都髙島屋S.C.
16:30–17:30｜祇園祭・お迎え提灯

從高島屋與四条河原町往八坂神社方向看お迎え提灯，剛好接晚間祇園祭活動。

京都髙島屋S.C.四条河原町八坂神社方向
🎯 終點：八坂神社
17:30–19:30｜高島屋・四条河原町晚餐

晚餐不要離開活動區太遠。高島屋或四条河原町最穩，吃完就能去四条大橋。

京都髙島屋S.C.四条河原町
🎯 終點：京都髙島屋S.C.
20:00 前後｜祇園祭・神輿洗

晚上核心是四条大橋神輿洗。這段終點直接設四条大橋。

四条河原町四条大橋神輿洗を見る
🎯 終點：四条大橋
20:45 後｜回飯店・山鉾町氣氛

看完神輿洗後往四条烏丸回飯店，順路感受山鉾町氣氛，不再加新景點。

四条大橋四条烏丸祇園祭 山鉾町イビススタイルズ京都四条
🎯 終點：イビススタイルズ京都四条

就地備選｜只放清水東山、高島屋、四条河原町

Day 3｜7/11（六）宇治茶店 → 平等院鳳凰堂

今日摘要

主軸是宇治茶店與宇治散策。只放宇治市內與回京都後順路，不混京都市區餐廳。

行程 Outline

上午｜京都 → 宇治

從飯店先到京都駅，再前往宇治。這段終點設宇治駅，方便查交通。

イビススタイルズ京都四条京都駅宇治駅
🎯 終點：宇治駅
中午前後｜宇治茶店

宇治茶店是這天核心。中村藤吉當主攻，其它茶店當同區替代，不要拉回京都市區。

宇治駅中村藤吉本店伊藤久右衛門三星園上林三入本店
🎯 終點：中村藤吉本店 宇治本店
下午｜平等院鳳凰堂・宇治川周邊

吃完茶店後走平等院，接宇治橋與宇治川，路線集中、好控制體力。

宇治茶店平等院鳳凰堂宇治橋宇治川
🎯 終點：平等院鳳凰堂
傍晚｜宇治 → 京都

傍晚回京都後，以京都站、四条烏丸、飯店休息為主，不固定排正式餐。

宇治駅京都駅イビススタイルズ京都四条
🎯 終點：イビススタイルズ京都四条

就地備選｜只放宇治與回京都後順路

宇治茶店中村藤吉本店伊藤久右衛門辻利 宇治本店三星園上林三入本店福寿園 宇治茶工房
宇治景點微調鳳翔館宇治上神社源氏物語ミュージアム
回京都後

只收斂在京都站、四条烏丸、飯店休息。先斗町與正式餐不列入固定備選。

Day 4｜7/12（日）南禪寺 → 岡崎 → 老舖巡禮

今日摘要

上午南禪寺與水路閣；中午前後到岡崎、平安神宮；下午寺町、三條、京都老舖；傍晚新京極、錦市場、四條收尾。

行程 Outline

上午｜南禪寺、水路閣

這段重點是寺院與磚造水路。終點設水路閣，方便從飯店規劃到南禪寺區。

飯店南禪寺南禪寺 三門南禪寺 水路閣
🎯 終點：南禪寺 水路閣
中午前後｜岡崎、平安神宮

南禪寺往岡崎很順，平安神宮與神苑是這段主軸。美術館只是備選，不硬塞。

南禪寺岡崎公園平安神宮平安神宮 神苑
🎯 終點：平安神宮
下午｜寺町、三條、京都老舖

從岡崎往寺町三條移動，進入茶、香、紙、扇子的老舖線。終點設一保堂，因為它最適合作為這段集合點。

岡崎寺町通一保堂鳩居堂松栄堂宮脇賣扇庵
🎯 終點：一保堂茶舗 京都本店
傍晚｜新京極、錦市場、四條

最後往新京極、錦市場、四条烏丸收尾。這段不再加遠點，終點回飯店。

寺町三條新京極錦市場四条烏丸飯店
🎯 終點：イビススタイルズ京都四条

就地備選｜只放南禪寺、岡崎、寺町三條、四条烏丸
