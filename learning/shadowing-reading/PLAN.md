# 《3 個月打造英語耳》私人互動電子書｜分批製作計畫

> 2026-10-11 · v1.0。全書製作時嚴格遵照原書順序與完整性；以**單一完整小節／一回 Practice**為一批。進度以 Drive 正本與當次驗收為準。

## 目標

- 完整翻譯全書日文為台灣繁中，所有原有英文 script、例句、題目與表達方式都完整保留英文。
- 嚴格保留原文順序、章節、標題、段落、圖表、發音標記、註解、欄位、圖說、頁碼、音訊標記與附錄。
- 日中逐段（盡可能句意單元）忠實配對；英文原文在任何模式都保留。
- 閱讀模式：全中文 `zh`、日文原文 `jp`、左右對照 `parallel`。**取消上下雙語 `bi`**。
- iPhone（320px 起）平行閱讀永遠為日文左／繁中右；英語逐字稿獨立全寬以利練習。
- 完整正文、原頁掃描圖，均只保存在 Google Drive 私人檔案；GitHub Pages 只有公開殼層、導航、控制程式與 README。

## 每批工作上限與驗收門檻

- 原則：**一個小節（約 4–8 原書頁）或一個 Practice**；如果有密集圖表、長對話、音標／連音標記，按實際量縮小到 2–4 頁。
- 完整流程：①列出來源 PDF 頁界 → ②逐頁核對 OCR（包含頁圖、腳註）→ ③日文完整翻譯／英文原封保留 → ④雙語分段對齊 → ⑤寫入新一批私人 HTML → ⑥品質核對與行動／桌面版面測試 → ⑦標示完成狀態。
- 任何尚未處理的頁、不可辨識字、表格或原圖，都記錄問題與未完成狀態，嚴禁跳頁。
- 每批上線前驗證三種顯示模式，至少 320／375／390／430／710／768／1024／1280px，且無整頁水平溢出；圖表與超寬元素可內部滑動。
- 修改既有私人 HTML 之前，必須先備份至同層 `_backup`，然後更新**同一 Drive File ID**；新獨立章節才另外建立新私人 ID。
- 原書錄音檔在取得前一律顯示為「音訊未提供」，瀏覽器 TTS 必須明確標示為合成語音。
- 不以本地 Chromium 測試取代真人 iPhone Safari＋Google OAuth 驗證。
